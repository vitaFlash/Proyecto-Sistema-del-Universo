# 🌌 Universo POO - Java Project

This Java project is a learning exercise focused on applying **object-oriented programming (OOP)** concepts through a universe-themed simulation. The code is organized in two parts, each in a separate Git branch.

---

## 📂 Branches Overview

| Branch     | Description |
|------------|-------------|
| `dev`      | Part 1: Basic OOP — classes, encapsulation, inheritance, and polymorphism. |
| `new-dev`  | Part 2: Advanced OOP — includes abstract classes and interfaces for better design. |

---

## ✅ Concepts Covered

### **Part 1 (`dev`)**
- Classes: `CuerpoCeleste`, `Planeta`, `Estrella`
- Encapsulation via private fields and public getters/setters
- Inheritance and method overriding
- Static polymorphism with overridden methods

### **Part 2 (`new-dev`)**
- Abstract class: `CuerpoCeleste`
- Interfaces: `Orbitable`, `Luminiscente`
- Dynamic polymorphism using `instanceof`
- Behavior-based separation (e.g., emitting light vs orbiting)
